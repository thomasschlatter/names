# NAME_PHONOLOGY_REGISTRY — folder layout

Paper: "Phonological gender marking in given names is a cross-linguistic
regularity decoupled from societal gender equality" (`paper_registry.Rmd`).

Tidied 2026-09-18. See `CLAUDE.md` for the project notes and open issues.

## The manuscript

| File | What it is |
|---|---|
| `paper_registry.Rmd` | the manuscript AND the analysis pipeline. The former `_regression_top30.py` now lives inside it as reticulate `{python}` chunks, so a knit regenerates the regression instead of reading a stale CSV. |
| `paper_registry.html` | last render |
| `paper_registry_backup_pre_reticulate_20260917.Rmd` | the version before the pipeline was moved in |

Knit with `rmarkdown::render("paper_registry.Rmd", output_format = "html_document")`.
It needs `PYTHON_BIN` (set in the setup chunk) to point at a Python with
panphon, pandas, numpy and scikit-learn, and eSpeak NG at the path in
`pipeline-constants`.

## Data

- `official_data_top30/` — the derived subset the regression reads (top 30 per
  sex per registry). `_build_top30.py` rebuilds it; note it does not reproduce
  the stored files, because the stored ones were built from top-30 ROWS rather
  than top-30 distinct names.
- `equality_data/`, `equality_final_v4.csv`, `gender_inequality_GII_SIGI.csv`,
  `grammatical_gender.csv`, `hofstede_dimensions.csv` — Analysis 3 inputs.
- `official_ipa_*` — pipeline outputs (features, coefficients, summary, G2P
  audit, unparsed-symbol report).

The registry harvest itself is NOT here. One copy lives at

## Scripts

Collection and audit tooling, all runnable standalone:

- `_build_top30.py` — rebuild the regression subset from the shared harvest
- `_add_source_column.py` — attribute every name list, write `audits/sources_lookup.csv`
- `_collect_country_sources.py` — pull the per-country source docs in from GIVEN_NAMES
- `_audit_sources.py` — which data files can be traced to a source
- `_audit_language_assignment.py` — each registry's transcriber vs its actual names
- `_validate_coverage.py`, `_validate_coverage2.py` — human-reference coverage per source
- `_harvest_wiktionary_ipa.py` — recover human IPA for names WikiPron misses
- `_japanese_*.py` — readings from JMnedict, ja.wikipedia and Meiji Yasuda,
  with sex from Wikidata P21

`_regression_top30.py` is kept because several scripts import its helpers, but
the manuscript no longer uses it; the pipeline inside the Rmd is authoritative.
`_check_de_long.py`, `_check_missing_features.py`, `_compute_new_features_d.py`
and `_spot_ipa_17.py` are old one-off probes (two read files that have never
existed in this repo).
