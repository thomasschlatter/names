regularity decoupled from societal gender equality"**

## Regression subset
- `official_data_top30/` = top 30 F + 30 M per registry by count; `_manifest.csv`
  gives per-registry F/M coverage. CJK preserved (UTF-8).
- `_regression_top30.py` runs `P(male) ~ features + source FE` on that subset.
  Paths are resolved from the script's own location (`BASE = Path(__file__)...`),
  so the script and `official_data_top30/` must stay together.
- This is the **panphon + eSpeak** pipeline, not the lexicon paper's ipapy + CMU
  one. Run with `--filter-g2p-artifacts` (Japanese kanji is 96.7% artifacts).
- Clean subset result: AUC ~0.940; `pf_son` negative (female more sonorant)
  replicates; back/consonantal pattern male, open/long/strident pattern female.

### Abjad-script exclusion (Hebrew/Arabic)
Unvocalized registry text yields consonant skeletons from eSpeak, distorting
every vowel/sonority feature, and the artifact detector cannot see it. Excluded
outright via `EXCLUDE_SOURCES` in `_regression_top30.py`: `official_israel`,
`official_israel_jewish_hebrew`, `official_morocco`, `official_tunisia`.
