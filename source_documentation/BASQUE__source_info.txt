HOW TO EXTRACT BASQUE DATA FROM INE FILES:
The INE annual nomnac files include a tab or section "Comunidades Autónomas" with top 10 names
per autonomous community. The Basque Country (País Vasco / Euskadi) data is in these files.
Basque-specific given names (Ane, Oihan, Iker, Amaia, Markel, Eneko, etc.) will appear there.

NOTES:
- INE data covers all of Spain; Basque Country names are a subset
- Basque names are also visible in the "nombres_mas_frecuentes" file (living population by province)
- The Eustat open data portal (opendata.euskadi.eus) publishes its own bilingual name dataset;
  direct access was blocked from this machine — try from a different network
- The "izendegia" (Basque official name dictionary) is also published at opendata.euskadi.eus
