== NOTES ON DATA ==
- Language family: Kartvelian (South Caucasian) — completely unrelated to Indo-European
- Script: Georgian (Mkhedruli script: გიორგი, ნინო, დავით...)
- The GitHub dataset includes Georgian script + Latin transliteration — useful for NLP
- Most common names reflect strong Georgian cultural naming tradition:
  Male: გიორგი (Giorgi), დავით (Davit), ლევან (Levan), ირაკლი (Irakli)
  Female: ნინო (Nino), მაია (Maia), თამარ (Tamar), ნანა (Nana)
- No birth-year breakdown available in this dataset; it is a population-level snapshot
