LINGUISTIC NOTES
===========================================================
- Sinhala (Sinhalese) is an Indo-Aryan language, part of the Indo-Iranian branch
  of Indo-European; it descended from Sanskrit via Pali
- Written in the Sinhala script (abugida), unique to this language
- All names in saved files are romanized transliterations
- Sinhala is spoken by ~70% of Sri Lanka's population (~17 million speakers)
- Sri Lanka is officially bilingual: Sinhala and Tamil
- Tamil names (Dravidian family) appear in Sri Lankan name data but are a
  separate language family from Sinhala
- Muslim Sri Lankan names (Mohamed, Fathima, Abdul) reflect Arabic/Islamic
  naming conventions and constitute a large portion of the most common names
- Common Sinhala name structure: compound names (given name + father's name
  or caste/village names); given names often drawn from Sanskrit/Pali
- Typical Sinhala male name patterns: ends in -a (Kasun, Nuwan, Tharindu);
  feminine names often end in -i, -a, -sha (Thilini, Sanduni, Sachini)
- The name "Fernando" (rank 33, 66,600 bearers) reflects the Portuguese
  colonial period (16th-17th century) influence on Sinhalese surnames used
  as given names
