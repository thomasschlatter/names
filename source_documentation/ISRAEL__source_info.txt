YEARS COVERED

  t8.xlsx (newborn frequency): 2024 births
  2022_births_release/: 2022 births

FILE FORMAT
  Microsoft Excel (.xlsx) and PDF

LANGUAGE
  Hebrew; column headers include:
    שם פרטי (first name), סה"כ (total), אחוז מסה"כ השמות (% of all names)
  Population group sheets:
    בנות יהודיות = Jewish girls, בנים יהודים = Jewish boys,
    בנות מוסלמיות = Muslim girls, בנים מוסלמים = Muslim boys,
    בנות נוצריות-ערביות = Christian-Arab girls, בנים נוצרים-ערבים = Christian-Arab boys,
    בנות דרוזיות = Druze girls, בנים דרוזים = Druze boys

KEY FILE: cbs_2024births_t8.xlsx
  Most useful for name frequency analysis. Contains names given to ≥5 babies in each
  sex/religion group born in 2024, with count and % of total.
  Example 2024 top names: Abigail (Jewish girls), David (Jewish boys), Muhammad (Muslim boys)

NOTES
  - CBS releases annual name data; releases lag by ~1 year (2024 births released Dec 2025)
  - Data includes all population groups: Jewish, Muslim, Christian-Arab, Druze
  - Names given to fewer than 5 babies are suppressed for privacy
  - No authentication required; all files are freely downloadable from cbs.gov.il
